# 企业客服 SLA 与升级路由

Copyright © 2026 上海如静知华信息科技有限公司 · <https://www.zhuatech.cn/>

`POST /api/enterprise/aicc/sla-escalation` 面向语音、在线聊天、邮件和社交渠道，按优先级、已用时、服务时限、客户情绪、投诉、重点客户、监管事项与安全风险计算统一升级决策。

- `MONITOR`：服务健康，保持当前渠道队列。
- `PRIORITIZE`：达到 SLA 预警线、重点客户或责任坐席不可用，提升排序。
- `ESCALATE`：已经超期、投诉、高负向情绪或 P1 交互，转班长队列。
- `EMERGENCY`：安全风险或监管案件，直接进入安全/合规专席。

响应同时提供 SLA 使用率、剩余分钟、目标队列、可解释原因和处置动作，可由队列调度器、工单系统或值班通知系统直接消费。演示实现是确定性规则；生产环境可把 SLA 配置、技能组、排班与客户分层接入企业主数据。
